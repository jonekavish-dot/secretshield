How it works

Gate 1

Pre-commit hook

Scans the staged files on the developer's laptop. A Critical or High finding cancels the commit before anything is saved to history.

Gate 2

CI gate

GitHub Actions re-scans every push and pull request, so a hook skipped with --no-verify still fails the pipeline.

Gate 3

This service

Receives the redacted report from CI over a token-protected endpoint and shows it here, with fix steps on every finding.

Safe secret handling

  • Secrets are read from environment variables, never written in code.
  • .env.example lists variable names only, never values. .env is in .gitignore.
  • Every report masks its match: AKIA************MPLE. No log or page holds a full secret.
  • A leaked key is rotated at the provider, not just deleted from the file: Git keeps every old version.
  • If a secret was already pushed, purge it with git filter-repo and rotate it anyway.
